# Retired card-icon assets

This recoverable recycle area preserves the pre-spec-06 raster card renderer:

- `card-icons/` contains the 25 PNG symbols and their original README formerly staged from `game/assets/card-icons/`.
- `iconMap.legacy.ts` contains the retired tag/stat-to-PNG mapping.

The active card renderer uses attributed SVG symbols from `game/assets/card-art-icons/`. Nothing in this directory is staged into `game/public/` or emitted by the production build.
